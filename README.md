# Terciarización económica y cambio estructural en Nuevo León

## Sobre el estudio

Este repositorio contiene los materiales de reproducibilidad de una investigación sobre la transformación económica de Nuevo León entre 1980 y 2024.

## Contenido

- **Bases de datos:** información utilizada en el análisis.
- **Código en R:** procedimientos estadísticos, econométricos y elaboración de figuras.
- **Documento HTML:** presentación de los análisis, resultados y visualizaciones.
- **Documentación:** diccionario de variables y materiales complementarios.

## Reproducción de resultados

Los análisis se desarrollaron en RStudio. Para reproducirlos, se recomienda descargar el repositorio completo, abrir el proyecto localmente y ejecutar los archivos de R utilizando las bases de datos incluidas.

El archivo HTML permite consultar los resultados sin necesidad de ejecutar el código.

## Fuentes

Las fuentes estadísticas y las transformaciones realizadas se documentan en el manuscrito y en los materiales del repositorio.
