Material de replicación del estudio

Título del estudio:
Terciarización Económica Y Cambio Estructural En Nuevo León

Este repositorio contiene los archivos utilizados para la construcción de variables, elaboración de gráficas, análisis descriptivo y econométrico, análisis interestatal y regional, y documentación complementaria del working paper sobre la terciarización económica de Nuevo León entre 1980 y 2024.
