# Terciarización económica y cambio estructural en Nuevo León

Este repositorio contiene los materiales de reproducibilidad de un estudio sobre la transformación económica de Nuevo León entre 1980 y 2024.

## Contenido del repositorio

- **01_bases_de_trabajo:** base analítica de Nuevo León y base comparativa interestatal y regional.
- **02_codigo_R:** códigos utilizados para los análisis estadísticos, econométricos y gráficos.
- **03_figuras:** figuras utilizadas en el artículo.
- **04_resultados:** documentos HTML con los análisis y resultados.
- **05_documentacion:** diccionario de variables y documentación metodológica complementaria.

## Reproducibilidad

Los análisis se desarrollaron en R y RStudio. Para reproducirlos, descargue el repositorio, consulte las bases de datos y ejecute los códigos correspondientes.

Los archivos HTML permiten consultar los resultados sin ejecutar el código.

## Anonimización

Este repositorio se presenta de forma anonimizada para preservar la identidad de los autores durante el proceso de evaluación por pares.
